# Practica 1: Preparacion y Verificacion de Entornos de Desarrollo Scala 
 
## Estructura del Repositorio 
- parte1/notebook/: Cuaderno interactivo JupyterLab con Almond kernel. 
- parte2/sbt_project/: Proyecto sbt gestionado con Visual Studio Code y Metals. 
- parte3/scala-intellij/: Proyecto scala-intellij configurado en IntelliJ IDEA Community. 
- images/: Evidencias graficas de configuracion y ejecucion en formato .jpg. 
 
## Entorno 1 - JupyterLab + Almond + Scala 2.12.21 
- Registro del kernel Almond 0.13.14 sobre Scala 2.12.21 y Java 17. 
- Verificacion interactiva de propiedades del sistema, variables, operaciones y colecciones. 
 
## Entorno 2 - VS Code + sbt + Metals 
- Gestion de build.sbt con sbt 1.10.7 y Scala 2.12.21. 
- Compilacion con sbt compile y ejecucion satisfactoria de Main.scala con sbt run. 
 
## Entorno 3 - IntelliJ IDEA Community + Scala Plugin 
- Creacion del proyecto sbt scala-intellij con SDK Eclipse Temurin JDK 17. 
- Ejecucion exitosa tanto desde el IDE como mediante sbt run en terminal integrada.
